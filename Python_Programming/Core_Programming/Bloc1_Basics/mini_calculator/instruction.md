# 🧮 Mini Calculator

**Bloc 1 — Basics**
**Difficulté / Difficulty:** ⭐⭐☆

---

## 🇫🇷 Énoncé

Écris un programme qui simule une calculatrice basique.  
Le programme demande à l'utilisateur deux nombres et une opération, puis affiche le résultat.

**Exemple :**
```
Entrez le premier nombre : 10
Entrez le second nombre : 3
Choisissez une opération (+, -, *, /) : /
Résultat : 10 / 3 = 3.33
```

**Contraintes :**
- Les quatre opérations doivent être supportées : `+`, `-`, `*`, `/`
- La division par zéro doit être gérée — affiche un message d'erreur au lieu de planter
- Le résultat d'une division doit être arrondi à 2 décimales

**Stretch 🚀 :**  
Ajoute le modulo `%` comme cinquième opération.

---

## 🇬🇧 Instructions

Write a program that simulates a basic calculator.  
The program asks the user for two numbers and an operation, then displays the result.

**Example:**
```
Enter the first number: 10
Enter the second number: 3
Choose an operation (+, -, *, /): /
Result: 10 / 3 = 3.33
```

**Constraints:**
- All four operations must be supported: `+`, `-`, `*`, `/`
- Division by zero must be handled — display an error message instead of crashing
- Division results must be rounded to 2 decimal places

**Stretch 🚀:**  
Add modulo `%` as a fifth operation.
