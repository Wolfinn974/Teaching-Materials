# ➕ Is It Positive?

**Bloc 1 — Basics**
**Difficulté / Difficulty:** ⭐☆☆

---

## 🇫🇷 Énoncé

Écris un programme qui demande à l'utilisateur de saisir un nombre entier.  
Le programme doit afficher si ce nombre est **positif**, **négatif**, ou **nul**.

**Exemple :**
```
Entrez un nombre : -7
Ce nombre est négatif.

Entrez un nombre : 0
Ce nombre est nul.

Entrez un nombre : 42
Ce nombre est positif.
```

**Contraintes :**
- Utilise une structure `if / elif / else`
- Les trois cas doivent être gérés

---

## 🇬🇧 Instructions

Write a program that asks the user to enter an integer.  
The program must display whether that number is **positive**, **negative**, or **zero**.

**Example:**
```
Enter a number: -7
This number is negative.

Enter a number: 0
This number is zero.

Enter a number: 42
This number is positive.
```

**Constraints:**
- Use an `if / elif / else` structure
- All three cases must be handled
