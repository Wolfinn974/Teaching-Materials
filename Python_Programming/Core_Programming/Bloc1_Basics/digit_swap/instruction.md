# 🔢 Digit Swap

**Bloc 1 — Basics**
**Difficulté / Difficulty:** ⭐☆☆

---

## 🇫🇷 Énoncé

Écris un programme qui demande à l'utilisateur de saisir un nombre entier à deux chiffres.  
Le programme doit afficher ce nombre avec ses chiffres inversés.

**Exemple :**
```
Entrez un nombre à deux chiffres : 42
Résultat : 24
```

**Contraintes :**
- Tu ne peux pas utiliser de slicing ou de méthodes de string
- Tu dois utiliser les opérateurs arithmétiques `//` et `%`
- Le nombre saisi est toujours un entier positif à exactement deux chiffres

**Indice :**  
Comment isoler le chiffre des dizaines ? Et celui des unités ?

---

## 🇬🇧 Instructions

Write a program that asks the user to enter a two-digit integer.  
The program must display that number with its digits swapped.

**Example:**
```
Enter a two-digit number: 42
Result: 24
```

**Constraints:**
- You may not use slicing or string methods
- You must use arithmetic operators `//` and `%`
- The input is always a positive integer with exactly two digits

**Hint:**  
How do you isolate the tens digit? And the units digit?
