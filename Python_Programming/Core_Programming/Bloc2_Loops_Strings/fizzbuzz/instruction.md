# 🔢 FizzBuzz

**Bloc 2 — Loops & Strings**
**Difficulté / Difficulty:** ⭐⭐☆

---

## 🇫🇷 Énoncé

Écris un programme qui affiche tous les nombres de 1 à 100, en remplaçant :
- les multiples de 3 par `Fizz`
- les multiples de 5 par `Buzz`
- les multiples de 3 **et** de 5 par `FizzBuzz`

**Exemple (extrait) :**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
...
```

**Contraintes :**
- Une seule boucle `for`
- Utilise l'opérateur modulo `%`
- L'ordre des conditions compte — réfléchis avant de coder

**Indice :**  
Que se passe-t-il si tu vérifies `% 3` et `% 5` séparément avant de vérifier `% 15` ?

---

## 🇬🇧 Instructions

Write a program that prints all numbers from 1 to 100, replacing:
- multiples of 3 with `Fizz`
- multiples of 5 with `Buzz`
- multiples of both 3 **and** 5 with `FizzBuzz`

**Example (excerpt):**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
...
```

**Constraints:**
- A single `for` loop
- Use the modulo operator `%`
- The order of conditions matters — think before you code

**Hint:**  
What happens if you check `% 3` and `% 5` separately before checking `% 15`?
