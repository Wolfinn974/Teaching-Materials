# 🔤 Reverse Alphabet

**Bloc 2 — Loops & Strings**
**Difficulté / Difficulty:** ⭐⭐☆

---

## 🇫🇷 Énoncé

Écris un programme qui affiche l'alphabet en minuscules dans l'ordre inverse, sur une seule ligne, avec un espace entre chaque lettre.

**Exemple :**
```
z y x w v u t s r q p o n m l k j i h g f e d c b a
```

**Contraintes :**
- Tu dois utiliser une boucle `for`
- Tu dois utiliser `chr()` et `ord()`
- Tu ne peux pas stocker l'alphabet dans une variable pour ensuite le renverser — le parcours doit se faire directement à l'envers

**Indice :**  
`range()` accepte un troisième argument. Que se passe-t-il si ce troisième argument est négatif ?

**Stretch 🚀 :**  
Affiche les codes ASCII correspondants sous chaque lettre :
```
z   y   x  ...
122 121 120 ...
```

---

## 🇬🇧 Instructions

Write a program that prints the alphabet in lowercase in reverse order, on a single line, with a space between each letter.

**Example:**
```
z y x w v u t s r q p o n m l k j i h g f e d c b a
```

**Constraints:**
- You must use a `for` loop
- You must use `chr()` and `ord()`
- You may not store the alphabet in a variable and reverse it — the loop must iterate backwards directly

**Hint:**  
`range()` accepts a third argument. What happens if that third argument is negative?

**Stretch 🚀:**  
Print the corresponding ASCII codes below each letter:
```
z   y   x  ...
122 121 120 ...
```
