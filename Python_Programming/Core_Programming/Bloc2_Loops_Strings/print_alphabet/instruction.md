# 🔤 Print Alphabet

**Bloc 2 — Loops & Strings**
**Difficulté / Difficulty:** ⭐☆☆

---

## 🇫🇷 Énoncé

Écris un programme qui affiche l'alphabet en minuscules sur une seule ligne, avec un espace entre chaque lettre.

**Exemple :**
```
a b c d e f g h i j k l m n o p q r s t u v w x y z
```

**Contraintes :**
- Tu dois utiliser une boucle `for`
- Tu dois utiliser `chr()` et `ord()` — pas de string `"abcde..."` hardcodée
- Toutes les lettres sur une seule ligne

**Stretch 🚀 :**  
Affiche aussi l'alphabet en majuscules sur la ligne suivante.

---

## 🇬🇧 Instructions

Write a program that prints the alphabet in lowercase on a single line, with a space between each letter.

**Example:**
```
a b c d e f g h i j k l m n o p q r s t u v w x y z
```

**Constraints:**
- You must use a `for` loop
- You must use `chr()` and `ord()` — no hardcoded `"abcde..."` string
- All letters on a single line

**Stretch 🚀:**  
Also print the uppercase alphabet on the next line.
