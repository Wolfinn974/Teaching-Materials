# 🔡 Count Vowels

**Bloc 2 — Loops & Strings**
**Difficulté / Difficulty:** ⭐⭐☆

---

## 🇫🇷 Énoncé

Écris un programme qui demande à l'utilisateur de saisir une phrase, puis affiche le nombre de voyelles qu'elle contient.

**Exemple :**
```
Entrez une phrase : Hello, World!
Nombre de voyelles : 3
```

**Contraintes :**
- Les voyelles sont : `a e i o u` (et leurs majuscules)
- La casse ne doit pas avoir d'importance — `A` et `a` comptent tous les deux
- Utilise une boucle `for` pour parcourir la phrase

**Stretch 🚀 :**  
Affiche le détail — combien de fois chaque voyelle apparaît :
```
a: 0
e: 1
i: 0
o: 2
u: 0
Total: 3
```

---

## 🇬🇧 Instructions

Write a program that asks the user to enter a sentence, then displays the number of vowels it contains.

**Example:**
```
Enter a sentence: Hello, World!
Number of vowels: 3
```

**Constraints:**
- Vowels are: `a e i o u` (and their uppercase versions)
- Case should not matter — `A` and `a` both count
- Use a `for` loop to iterate through the sentence

**Stretch 🚀:**  
Display the breakdown — how many times each vowel appears:
```
a: 0
e: 1
i: 0
o: 2
u: 0
Total: 3
```
