# 🐍 Programming — Python

> Project-based learning path for beginner to intermediate students.
> No 100-page syllabus. Concept sheets, cheat sheets, exercises, and projects.

---

## 🗺 Structure

This section is split into two parts.

**Part 1 — Core Programming** covers the fundamentals over roughly half the year, from variables to object-oriented programming. Each block follows the same pattern: concept sheet → exercises → project.

**Part 2 — Applied Tracks** lets students go deeper based on what they actually want to build: games, web apps, or security tools.

## 🧭 How to Use This Repo

Each block folder contains:
- `README.md` — block overview, objectives, prerequisites
- `cheatsheet.md` — concept reference card (print-friendly)
- `exercises/` — individual exercise files with instructions
- `projects/` — larger projects with starter code if applicable

**Philosophy:** No heavy theory upfront. Concepts are introduced when they're needed, demonstrated through code, and reinforced through exercises. Projects are the real lessons.
