---

## 🎯 Learning Objectives

By the end of this project, students will be able to:

* [ ] Control a character using keyboard input
* [ ] Use loops to constantly update movement
* [ ] Detect collisions using sensors
* [ ] Prevent the player from passing through walls
* [ ] Implement a win condition
* [ ] Understand basic game flow (start → play → win)

## 📝 Instructor Notes

* This is often the **first real project**, so go slow and let students experiment.
* Key teaching points:

  * Difference between *pressing a key* and *holding a key*.
  * Why we need a forever loop for movement.
  * How collision detection works (especially the “touching color” block).
* Common issues:

  * Students make the player too fast → collision doesn’t register.
  * Forgetting to “move back” after collision, so the player clips through walls.
* Encourage students to test often and fix bugs themselves.
* Good discussion question:

  > “Why does your player sometimes go through the wall?”
