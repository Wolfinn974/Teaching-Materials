# 🎭 Comic Strip (Scratch)

| **Level**         | Beginner                                          |
| **Duration**      | 2 sessions × ~1.5h                                |
| **Prerequisites** | Basic familiarity with Scratch sprites and blocks |

## 🎯 Learning Objectives

By the end of this project, students will be able to:

* [ ] Create a short story using multiple sprites
* [ ] Use timing and sequencing to control dialogue
* [ ] Animate characters using costumes
* [ ] Switch scenes and backgrounds
* [ ] Coordinate multiple characters in a scene

---

## 📝 Instructor Notes

* This project focuses more on **logic, timing, and storytelling** than technical difficulty.

* Encourage students to:

  * Plan their story first (who, what, where, when)
  * Use clear sequencing (don’t trigger all dialogue at once)
  * Experiment with costumes for emotions and reactions

* Common issues:

  * All characters speaking at the same time → remind them about sequencing
  * Timing too fast or too slow → adjust `wait` blocks
  * Students forgetting to switch backdrops or costumes

* Extension ideas:

  * Add sound effects or music
  * Create branching dialogues
  * Use user input to change the story
