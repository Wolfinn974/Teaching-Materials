# Scratch – Project-Based Learning

This folder contains a collection of **Scratch projects and teaching materials** used to introduce programming concepts to beginners, especially young learners.

The projects are designed to progressively introduce core programming ideas through **games and interactive experiences**, with a strong focus on creativity, problem-solving, and iteration.

Each project introduces specific concepts such as movement, logic, collisions, events, variables, animation, and user interaction.

---

## 🧱 Project Progression

Projects are ordered by increasing complexity and designed to be completed over multiple sessions.

### 1️⃣ Maze Game (Introduction to Basics)

**Goal:** Introduce the fundamentals of programming and Scratch.

**Concepts covered:**

* Movement controls
* Collision detection (walls and obstacles)
* Simple win condition
* Use of events and conditions

> 📝 Note: No demo available yet — will be recreated.

---

### 2️⃣ Comic Strip (Animation & Storytelling)

**Goal:** Learn sequencing, animation timing, and basic storytelling.

**Concepts covered:**

* Dialogue bubbles
* Timed events
* Sprite switching and animation
* Scene transitions

This project helps students understand the idea of **sequence and timing**, which is foundational for all future projects.

---

### 3️⃣ Endless Runner

**Goal:** Build a side-scrolling game with increasing difficulty.

**Concepts covered:**

* Continuous movement
* Spawning obstacles
* Collision detection
* Scoring system
* Difficulty progression

This introduces **game loops** and the idea of dynamic gameplay.

---

### 4️⃣ Pokémon-like Game

**Goal:** Create a small RPG-style game with movement and interactions.

**Concepts covered:**

* Top-down movement
* Map design
* Basic combat logic
* Scene transitions
* Simple UI

This project introduces **state management** and player progression.

---

### 5️⃣ Street Fighter-like Game

**Goal:** Create a basic 1v1 fighting game.

**Concepts covered:**

* Character movement
* Hit detection
* Attack logic
* Health systems
* Multiplayer controls (local)

Students learn about **interactions between objects**, timing, and game balance.

---

### 6️⃣ Friday Night Funkin’-like Rhythm Game

**Goal:** Create a rhythm-based game with timing and inputs.

**Concepts covered:**

* Beat-based mechanics
* Timing accuracy
* User input handling
* Visual feedback

This project focuses on **precision, rhythm, and synchronization**.

## 🧠 Teaching Philosophy

* Projects are introduced gradually, increasing in complexity.
* Students are encouraged to experiment rather than copy.
* Debugging and problem-solving are treated as core skills.
* Creativity and iteration are encouraged at every step.

---

## 📌 Notes for Teachers

* Each project can be split into multiple sessions depending on the group’s level.
* Concepts can be revisited and expanded as students progress.
* Projects are flexible — they can be simplified or expanded based on student ability.
