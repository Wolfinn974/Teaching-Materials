# 🎮 Endless Runner (Scratch)

> Build an endless side-scrolling runner game where the player avoids obstacles and tries to survive as long as possible.

[![Scratch Demo](https://img.shields.io/badge/Scratch-Demo-orange?logo=scratch)](https://scratch.mit.edu/projects/1247004043)

---

## 📋 Quick Info

|                   |                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------ |
| **Tool**          | Scratch                                                                              |
| **Target age**    | 8 – 14 years old                                                                     |
| **Level**         | Beginner → Intermediate                                                              |
| **Duration**      | 3 sessions × ~1.5h                                                                   |
| **Prerequisites** | Basic movement in Scratch (arrow keys), understanding of loops and simple conditions |

---

## 🎯 Learning Objectives

By the end of this project, students will be able to:

* [ ] Create continuous scrolling backgrounds
* [ ] Implement jump mechanics with basic gravity
* [ ] Spawn and manage obstacles using clones
* [ ] Detect collisions and handle game over states
* [ ] Create and update a score system
* [ ] Balance gameplay difficulty over time

## 🚀 How to Use

1. Open the starter project in Scratch.
2. Follow `lesson-plan.md` step-by-step across the sessions.
3. Use the `/demo` folder only as a reference for instructors — avoid sharing it with students before they finish.

---

## 📝 Instructor Notes

* Start by showing the finished version so students understand the goal.
* The most common blockers are:

  * Jumping feels too floaty or too heavy (gravity tuning)
  * Obstacles spawn too fast or too slow
  * Collision detection not triggering correctly
* Encourage experimentation: changing jump height, speed, difficulty curve, or visuals.
* Make students explain what their code does — especially clone behavior.
* For advanced students:

  * Add multiple obstacle types
  * Add a day/night cycle or visual theme
  * Add sound effects or combo scoring
