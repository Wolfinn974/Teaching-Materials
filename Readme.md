# Teaching Material – Practical Programming & Robotics Education

This repository is a curated collection of **teaching materials, lesson plans, and project-based learning resources** designed to help teach programming and robotics to beginners and young learners (typically ages 7–15).

It focuses on **practical learning**, where students learn by building real projects instead of memorizing abstract theory.

The content is based on real classroom experience teaching:

* Block-based programming
* Python programming
* Game development
* Educational robotics
* Problem-solving and debugging mindset

This repository is not just a collection of code — it is a **toolkit for teachers, mentors, and self-learners** who want structured, engaging learning paths.

## 🎯 Philosophy

This repository follows a few core principles:

* **Learn by doing** — Every concept is tied to a practical project.
* **Iteration > Perfection** — Students are encouraged to experiment and improve.
* **Understand, don’t copy** — Copy/paste is discouraged; thinking is encouraged.
* **Mistakes are part of the process** — Debugging is treated as a skill.
